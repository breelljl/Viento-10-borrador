# mi-hotel-site

Prototipo estático del sitio web del hotel (Home + Ficha de habitación).

Cómo ejecutar localmente:
1. Clona el repo: `git clone https://github.com/tu-usuario/mi-hotel-site.git`
2. Entra en la carpeta: `cd mi-hotel-site`
3. Sirve localmente:
   - Python 3: `python -m http.server 8000` y abre http://localhost:8000
   - O con Node: `npx serve .`

Estructura:
- index.html
- styles.css
- script.js
- images/ (imágenes exportadas desde Figma)

Cómo contribuir:
- Crea una rama: `git checkout -b feature/nombre`
- Haz cambios, commit y push. Abre Pull Request en GitHub.

Notas:
- Optimiza las imágenes antes de commitear (WebP o JPG comprimido).
- No subas archivos muy pesados (usar Git LFS si es necesario).
